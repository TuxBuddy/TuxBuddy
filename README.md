## What is TuxBuddy?

TuxBuddy is an open-source cloud-native ecosystem that watches over every cluster you run — from your first dev cluster to a fleet of production ones. One buddy, every layer: Kubernetes automation, eBPF observability, network diagnostics, and MCP-native AI operations.

TuxBuddy 是一个开源云原生运维生态：Kubernetes 自动运维、eBPF 可观测、网络故障诊断与 MCP 智能运维。一只企鹅，照看你的所有集群。

## Capability Map

| Capability | Description | 简述 |
|---|---|---|
| **Kubernetes Ops** | Audits, healing and routine operations — done on intent | K8s 自动运维 |
| **eBPF Observability** | Runtime visibility with zero code changes | eBPF 零侵入可观测 |
| **Network Diagnostics** | Trace any failed request to its root cause | 网络故障根因定位 |
| **MCP Native** | Every capability is a tool your AI agents can call | 能力封装为 MCP 工具 |
| **Multi-Cluster** | Dev to prod, ARM to x86 — anywhere K8s runs | 跨集群统一管理 |

## Brand & Mascot

The TuxBuddy mark is a minimal geometric take on **Tux, the Linux penguin**, drawn as a modern app icon (dark squircle, flat shapes).

- `assets/icon.svg` — brand icon master
- `assets/favicon.svg` — simplified small-size favicon
- `assets/tux-official.svg` — the classic Tux vector by [Larry Ewing](http://isc.tamu.edu/~lewing/linux/), re-illustrated by Garrett LeSage, refined by IFo Hancroft (CC0)
